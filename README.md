Analise de vendas SQL
Objetivo:
Simular a análise de vendas de uma loja online utilizando SQL.

Ferramentas:
– SQL

Estrutura:
– Criação da tabela de vendas
– Inserção de dados simulados
– Consultas para análise de faturamento e volume de vendas

Análises realizadas:
– Total de vendas por produto
– Produto mais vendido

Conclusão:
A análise permite identificar quais produtos geram maior faturamento e maior volume de vendas.
